# Code of Conduct

dgpu adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. ([中文版](https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/))

In short: be respectful and constructive, assume good faith, and keep discussions about the work. Harassment, personal attacks and discriminatory language aren't tolerated in issues, pull requests, discussions or any other project space.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainer privately through [GitHub](https://github.com/baabanana). Don't report it in a public issue. Reports are handled confidentially. The maintainer may remove comments, lock threads, or block participants who violate this code, as described in the Covenant's enforcement guidelines.
